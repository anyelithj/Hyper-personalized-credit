# Hi there 👋
##  Reto Crédito Hiperpersonalizado
Es poder tener un lugar de control para gestionar cada proceso de crédito; esto es indispensable para un mayor crecimiento y para poder darle visibilidad y prioridad a las solicitudes de afiliados, sus ofertas y su despacho por canal. Con Crédito Hiperpersonalizado no hay espacio para pérdidas de información y así todo el equipo (operativo, comercial y de tecnología) podrá mantenerse conectado en una misma red.

### instalar y Corrar  App
- **Backend (FastAPI + MySQL):** ubícate en la carpeta `backend/`, instala con `pip install -r requirements.txt` y levanta el servidor con `uvicorn main:app --reload` (o con `docker-compose up -d --build` desde la raíz del proyecto).
- **Frontend (Next.js):** ubícate en la carpeta `frontend/`, instala todas las dependencias con `npm install` y corre el proyecto con `npm run dev`.
- Guía paso a paso completa, con la base de datos, la siembra del usuario admin y Docker: ver [`COMO-LEVANTAR-EL-PROYECTO.md`](./COMO-LEVANTAR-EL-PROYECTO.md).
